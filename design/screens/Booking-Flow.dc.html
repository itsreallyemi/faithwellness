The 15-minute rest rule

60 min session
rest
30 min
rest
9:0010:0010:1510:4511:00
valid(slot) ⇔ no busy b where
b.start < slot.end + 15m
&& b.end + 15m > slot.start
  • Three layers: Calendly after-event buffer = 15, server filter on freeBusy, and an opaque “Rest” block written to Google so outside bookings respect it too.
  • Grid: starts snap to :00 / :15 / :30 / :45.
  • Time zones: store UTC, render with the viewer’s IANA zone; counselor sees both.

Edge paths

invitee.canceled → delete Meet event + rest block, post note in thread.
Reschedule → arrives as cancel + new invitee; link by old_invitee.
Webhook retry → 2xx fast, work on queue; dedupe by URI.
Token expired → pause counselor’s listing, email to reconnect.
